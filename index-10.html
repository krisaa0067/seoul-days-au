Sebuah kisah tentang pesan yang salah kirim, bangku dekat jendela, dan seseorang yang diam-diam selalu menunggumu pulang.

Demo AU: Han Yuna × Kang Minjae
Tempat: Seorin High School, Seoul

Cara memainkan
Ketuk ikon aplikasi di layar. Buka chat untuk membalas pesan, tekan hati di feed, baca Notes, dan pilih keputusan cerita untuk membuka kelanjutan yang berbeda.
Untuk mempublikasikan: unggah file index.html ke repositori GitHub, lalu aktifkan Settings → Pages. Semua fitur demo berjalan tanpa server atau API eksternal.
